## Getting Started

This project is a **Refine + React + Vite + Ant Design + TypeScript** admin panel.

### Prerequisites

- **Node.js**: recommended **18 LTS** or **20 LTS**  
- **Package manager**: `pnpm` (install globally with `npm install -g pnpm`)

### Install dependencies

```bash
pnpm install
```

### Running the development server

```bash
pnpm dev
```

The dev server will usually be available at `http://localhost:5173/`.  
Refine Devtools may run on a separate port (e.g. `http://localhost:5001/`).

### Building for production

```bash
pnpm build
```

### Running the production server

```bash
pnpm start
```

The production preview will usually be available at `http://localhost:4173/`.
